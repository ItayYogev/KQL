# KQL Query Repository

The **KQL** folder houses a collection of custom queries developed as part of my day-to-day responsibilities to enhance the security posture of organizations. These queries are specifically tailored for the **Microsoft Defender XDR** platform, enabling security teams to detect threats proactively and respond swiftly to incidents.

Leveraging the power of **Kusto Query Language (KQL)**, these queries automate key threat detection processes. Each query can be customized to address unique organizational security requirements, helping to identify and mitigate threats before they lead to significant damage. Additionally, the **SOC Analysis Kit** provides pre-built tools that streamline incident response, aiding security teams in breach analysis and investigations.

> 📌 For additional queries recommended to elevate threat detection capabilities, check the **'Stars'** category on my GitHub profile.

---

## Project Overview

This repository is divided into three main components:

### 1. Detection Rules
Focused on strengthening threat hunting capabilities, this component includes:
- **Advanced Detection Rules:** Designed to identify evolving threat patterns.
- **Cyber Threat Intelligence (CTI) Integration:** Incorporates CTI feeds, enriching detection accuracy and expanding threat context.

### 2. Organizational Insights
Provides the CISO with comprehensive, actionable insights into the organization’s security landscape, helping to:
- **Assess Vulnerabilities:** Track vulnerability exposure and prioritize mitigation.
- **Visualize Threat Data:** Generate visual reports that assist in risk management and decision-making.

### 3. SOC Analysis Kit
Equips the security operations center (SOC) team with essential tools for detailed investigations, including:
- **Pre-built Analysis Queries:** Simplifies the analysis of security events and breach data.
- **Incident Response Resources:** Facilitates efficient and thorough incident response, enabling quick resolution and documentation.
